# Быстрый запуск

Деловая игра X-Lance «Спаси конференцию!» — React + Vite + TypeScript, небольшой Node-сервер для входа по ссылке.
Подробности (как идёт игра, развёртывание в X-Lance, архитектура) — в `README.md`.

## Что нужно

- Node.js 20.12+ (проверено на 24.x) и npm
- Аккаунт X-Lance (вход в игру — email + пароль X-Lance)

## Первый запуск

```bash
npm install
cp .env.example .env   # в Windows: copy .env.example .env
```

В `.env` проверьте `VITE_XLANCE_API_URL` — GraphQL-эндпоинт X-Lance
(в примере `https://dev.x-lance.ru/api/graphql`; без `.env` берётся `https://preview.x-lance.ru/api/graphql`).
Токены в `.env` не нужны — вход в UI. Срок жизни ссылки-приглашения — `XL_JOIN_INVITE_TIME` (по умолчанию `24h`).

## Разработка

```bash
npm run dev
```

Открыть http://localhost:5173 → войти аккаунтом X-Lance. Демо без настройки: `/?seed=1`.
Вход участников по ссылке (`/join`) и Админка (`/admin`) работают и в dev-режиме.

## Продакшн

```bash
npm run build
npm run build:server
npm run serve
```

Сервер слушает порт `PORT` (по умолчанию 8080), раздаёт `dist/` и API `/api/join`, `/api/admin/join-tenants`.
Список открытых для входа тенантов хранится в `.data/join-tenants.json` (создаётся сам).
За nginx достаточно проксировать всё на этот порт.

## Проверки

```bash
npm run typecheck
npm run test:engine
npm run test:data
```

`npm run test:smoke` и `npm run e2e` требуют браузер (Edge / Playwright) и доступ к X-Lance.

## Что лежит в архиве

- `src/` — фронтенд, `server/` — Node-сервер (`serve.ts` — точка входа), `scripts/`, `tests/`, `e2e/` — проверки
- `*.pdf`, `*.docx`, `*.xlsx` в корне — методичка, колода карточек и планы работ (источник данных игры)
- `example_for_UI/` — исходный прототип интерфейса, для справки
- В архив не входят `node_modules`, сборки (`dist`, `dist-server`), `.env` и `.data` — они создаются при запуске
