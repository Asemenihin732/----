# «Спаси конференцию!» — интерактивная версия деловой игры (X-Lance)

Одностраничное веб-приложение (без бэкенда): ведущий открывает план и бюджет проекта
каждой команды по очереди, команда выбирает одну из четырёх закрытых карт, на раскрытой
карте — один из вариантов; план, бюджет и KPI пересчитываются, после каждого раунда
показывается табло, в конце — итоги, номинации и разбор по PMBOK.

## Запуск

Нужен Node.js 20+.

```bash
cd app
npm install
npm run dev        # разработка, http://localhost:5173
npm run build      # продакшн-сборка в app/dist (статика, можно отдавать любым веб-сервером)
npm run preview -- --port 5173   # раздача собранной версии
```

## Стек

React 19 + TypeScript + Vite, Tailwind CSS 4, Framer Motion (анимации), Zustand (состояние).
Всё состояние партии хранится в памяти браузера, перезагрузка страницы начинает игру заново.

## Структура (`app/src`)

| Путь | Что внутри |
|---|---|
| `data/projects.ts` | 6 проектов: план работ, бюджет, доход, плановая маржа |
| `data/cards.ts` | все карточки (72 командные + универсальные и бонусные) с вариантами и эффектами |
| `data/deck.ts` | **колода из 18 карточек для раундов 1–3** (3 на команду) и шаги «Что сделать в X-Lance» |
| `store/gameStore.ts` | ход игры: команды, раунды, выбор карты и варианта |
| `store/kpi.ts` | формулы KPI и индекса проекта |
| `store/analysis.ts` | текстовые выводы по PMBOK после раунда и в финале |
| `components/` | экраны: старт, ход команды, табло раунда, итоги |

## Как работает колода

- В раундах 1–3 на экране у команды 4 закрытые карты, но **какую бы карту она ни выбрала,
  открывается карточка из `data/deck.ts`** для этой команды и раунда.
- Чтобы заменить карточку, поменяйте запись в `DECK` (`team`, `round`, `title`, шаги X-Lance).
  Базовая карточка (текст, эффекты) ищется в `cards.ts` по команде и названию; новые карточки
  без записи в `cards.ts` описываются в `BONUS_CARDS` в `deck.ts`.
- В текущей колоде две бонусные карточки с одним вариантом «Принять»: «Саундчек со звёздным
  гостем» (Сцена, раунд 2) и «Автобус-экскурсовод» (Логистика, раунд 1).
- Дни в вариантах считаются целыми днями (в `deck.ts` поле `days` переопределяет срок).
- Игра рассчитана максимум на 3 раунда: карточек для 4-го раунда в данных нет.

## Правила расчёта

- Индекс = (KPI срока + KPI маржи + удовлетворённость) / 3.
  KPI срока = базовый срок / фактический × 100; KPI маржи = факт. маржа % / плановая % × 100
  (при отрицательной марже — 0); удовлетворённость стартует со 100% и ограничена 40–130%.
- Вариант «запрос на изменение» (`isChangeRequest`) пересматривает и базовый план
  (срок, доход, расход), поэтому отклонения от плана не возникает.
- На стартовом экране можно выбрать число команд (1–6) и раундов (1–3).
